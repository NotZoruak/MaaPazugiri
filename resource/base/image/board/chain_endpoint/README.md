# 连线终点菱形模板

这组模板覆盖用户提供的四档外观。标签只记录模板外观，识别器不读取连接总数。

| 模板标签  | 来源截图   | 对应外观 |
| --------- | ---------- | -------- |
| `under_7` | 小于7.png  | 小于7    |
| `from_7`  | 达到7.png  | 7至13    |
| `from_14` | 达到14.png | 14至24   |
| `from_25` | 达到25.png | 25及以上 |

`profile.json` 保存原图相对路径、SHA-256、裁切范围和掩码顶点。原图保持只读；模板仅保留终点的白色菱形核心和邻近彩边，头顶数字、外圈光晕及大部分来线不进入匹配掩码。

`agent/vision/chain_endpoint.py` 在当前帧指定区域内提取明亮核心，再核对局部模板。参考布局为720×1280；同长宽比截图先归一化再还原原图坐标。核心尺寸用于抑制起点小星星，多档和多尺度的同位置命中在当前帧合并。静态模板可以缓存，候选坐标和识别结果不跨帧复用。

## 本次移动后的局部确认

调用独立识别器时传入 `analyze(image, board, move=ChainMovePositions(start, end))`；调用棋盘识别器时传入 `analyze(image, frame_id, chain_move=ChainMovePositions(start, end))`。两个坐标均使用输入截图坐标：`start` 是本次移动段开始前鼠标所在处，`end` 是移动后的实际停留处，不能把 `start` 固定为整条链最初的小星星位置。

只搜索两处附近的方形区域，开发参数为参考分辨率下每方向55像素；区域随输入分辨率同比例换算，并裁到当前棋盘范围。两处均未命中、动作位置无效或结果冲突时返回未知，不回退全盘寻找。区域重叠时合并相同菱形；标记与两端距离之差小于12参考像素，或两端距离小于24参考像素时，归属未知。标记还须落在所判动作端的检查区域内，区域归属与距离判断矛盾时同样未知。这些距离是开发参数，需要后续实战样本核对。

`move_outcome` 提供动作反馈：

| 值               | 含义                                               |
| ---------------- | -------------------------------------------------- |
| `target_reached` | 唯一大菱形位于目标附近，可作为本段已接入的视觉证据 |
| `still_at_start` | 唯一大菱形仍在本段起点附近，当前尚未确认接入目标   |
| `unknown`        | 未命中、多个候选、归属不清或输入无效               |
| 空值             | 未传动作参数，仅进行离线全盘诊断                   |

动作确认不要求饿鬼主体编号；高亮遮挡造成主体漏检时仍可输出菱形反馈。反馈本身不执行继续移动、等待、更换目标或松开鼠标。

棋盘识别结果中的 `chain_endpoint` 同时用于完整与轻量模式：

| 字段                  | 含义                                                       |
| --------------------- | ---------------------------------------------------------- |
| `status=detected`     | 当前帧存在唯一通过核对的大菱形                             |
| `status=not_detected` | 当前帧未找到足够证据，不能据此断言没有连线                 |
| `status=uncertain`    | 多个候选、布局矛盾或强光干扰，不能确认终点                 |
| `status=unavailable`  | 未安装菱形模板，未检查终点                                 |
| `markers`             | 当前帧候选中心、范围、外观标签与模板分数；分数不是正确概率 |
| `object_id`           | 关联到的当前帧普通饿鬼编号；关联不唯一或对象缺失时为空     |
| `association_status`  | `matched`、`ambiguous`、`unmatched` 或 `not_checked`       |

`object_id` 仅用于补充关联当前帧对象。高亮或遮挡导致饿鬼漏检时不补造对象；本次动作是否到达目标以 `move_outcome` 判断。未命中、多个候选或未知结果不能当作无条件结束拖动的依据。

当前每档只有一张开发截图，尚未完成独立场次评估。不同入线方向、强光、遮挡和录屏压缩可能影响识别，需要后续样本核对。
