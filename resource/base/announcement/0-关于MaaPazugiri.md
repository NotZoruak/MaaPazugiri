# 关于 MaaPazugiri

MaaPazugiri 是基于 **MaaFramework** 开发的《刀剑乱舞ぱずぎり》自动化助手，通过识别游戏画面和模拟操作，帮助绘卷守完成重复的主线关卡战斗。项目面向游戏官方日文界面，目目前仅推荐模拟器在 **1280\*720，240 DPI 分辨率** 下使用，仅通过游戏界面进行交互，不会修改游戏文件或读写游戏内存。

本项目是社区开发的第三方工具，与游戏运营方无关，遵循 **AGPL-3.0-or-later** 开源许可，仅供学习交流使用。

## 使用约定

使用自动化工具可能违反游戏服务条款，也可能造成账号或游戏进度等损失。请在了解相关风险后自行决定是否使用，并自行承担由此产生的后果。

请尊重其他玩家的游玩方式，不以使用自动化工具炫耀或嘲讽手动操作的玩家。请勿在游戏官方讨论群组、官方账号动态及相关评论区宣传或讨论 MaaPazugiri，也请勿携带官方活动标签传播。

## 一起完善 MaaPazugiri

项目仍在持续完善，功能和识别效果会随着实战验证逐步完善。目前已知乱舞期间仍可能误连保留颜色的饿鬼，且暂时不会支持活动关卡的战斗。后续以**Bug 修复、游戏版本适配、依赖更新**为主，同时按需评估新功能、新任务、新流程。

欢迎分享使用体验、反馈问题、提出建议或贡献代码。感谢每一位愿意使用、测试和帮助改进 MaaPazugiri 的朋友。
